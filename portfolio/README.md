# Portfolio

Portfolio personale di Gianfrizio - Sviluppatore Full Stack

## 🚀 Tecnologie utilizzate

- **Next.js 15** - Framework React per la produzione
- **TypeScript** - Tipizzazione statica
- **Tailwind CSS** - Framework CSS utility-first
- **Framer Motion** - Animazioni fluide
- **Lucide React** - Icone moderne

## 🌟 Caratteristiche

- ✅ Design moderno e professionale
- ✅ Completamente responsive
- ✅ Animazioni fluide
- ✅ Performance ottimizzate
- ✅ SEO friendly
- ✅ Form di contatto funzionale
- ✅ Galleria progetti interattiva

## 🎯 Sezioni

1. **Hero** - Presentazione principale con call-to-action
2. **About** - Biografia professionale e competenze
3. **Projects** - Galleria progetti con tecnologie utilizzate
4. **Contact** - Form di contatto e informazioni

## 🛠️ Installazione e utilizzo

```bash
# Clona il repository
git clone https://github.com/gianfrizio/PortFolio.git

# Entra nella directory
cd PortFolio/portfolio

# Installa le dipendenze
npm install

# Avvia il server di sviluppo
npm run dev

# Build per la produzione
npm run build

# Avvia il server di produzione
npm start
```

## 📱 Deployment

Il sito è ottimizzato per il deployment su:
- Vercel (consigliato)
- Netlify
- GitHub Pages

### Deploy su Vercel

1. Collega il repository GitHub a Vercel
2. Configura il build command: `npm run build`
3. Configura la directory di output: `out` (se usando static export)
4. Deploy automatico ad ogni push
